# 7Torres — Loja teste

Projeto estático pronto para GitHub Pages.

## Arquivos
- `index.html` — página principal
- `style.css` — visual responsivo
- `script.js` — catálogo, busca, filtros e WhatsApp
- `imagens/` — fotos dos produtos

## Como publicar
1. Crie um repositório no GitHub, por exemplo `7torres`.
2. Envie todos os arquivos mantendo a pasta `imagens`.
3. No GitHub: Settings → Pages.
4. Em Source, selecione `Deploy from a branch`.
5. Escolha `main` e `/ (root)`.
6. Salve e aguarde o link do GitHub Pages.

## Como acrescentar produtos
Abra `script.js` e adicione um novo objeto dentro de `produtos`, seguindo o mesmo formato dos quatro existentes. Coloque a nova imagem na pasta `imagens/`.
